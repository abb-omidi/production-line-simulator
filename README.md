# Production Line Simulator

Mobile/PWA version for iPhone and iPad.

Features: Normal, Gamma, Poisson, Exponential, Weibull and Triangular processing-time distributions; editable parameters; MTBF/MTTR; buffers; scrap; add/remove machines; simulation; Monte Carlo; throughput; cycle time; utilization; availability; OEE; bottleneck identification; local save/load; offline cache.

Use the GitHub Pages URL in Safari, then Share -> Add to Home Screen -> Open as Web App.
